# تطبيق المحاسبة المستقل — SQLite

هذه الحزم تختلف عن رابط الموقع وعن معاينة Expo. تحتوي ملفات البرنامج محليًا
وتخزن الحركات في ملفات SQLite داخل مساحة التطبيق، دون خادم ودون كاش متصفح.

## حفظ الحركات

- تحافظ طبقة IndexedDBShim على توافق واجهة المحاسبة الحالية مع SQLite الأصلية.
- لا تُرسل إشارة اكتمال المعاملة إلى الواجهة إلا بعد نجاح `COMMIT` في SQLite.
- إلغاء معاملة متعددة الجداول يلغي الكتابة كاملة.
- قاعدة البيانات تُفتح بإعداد `synchronous=FULL` وسجل WAL.
- إعدادات الواجهة والتفعيل المخزنة عبر localStorage توجَّه أيضًا إلى SQLite.
- في أول تشغيل، تُنقل نسخة من قاعدة الإصدار السابق داخل **نفس مساحة التطبيق**
  إن وجدت، دون حذف الأصل. لا يمكن قراءة بيانات متصفح خارجي من تطبيق آخر؛
  لنقلها، صدّر نسخة احتياطية من الموقع واستوردها داخل التطبيق.
- حذف بيانات التطبيق أو حذف مجلد قواعده يزيل البيانات. لا توجد حماية مطلقة
  من تلف الجهاز أو حذف الملفات؛ احتفظ بنسخ احتياطية.

## Android

المصدر في `android/`. ينشئ التطبيق ملفات SQLite في مجلد قواعد بيانات Android
الخاص به. لا يتضمن تصريح INTERNET. APK الناتج عن مهمة البناء الحالية **تجريبي**
بتوقيع تطوير، وليس إصدار توزيع نهائيًا. التحديثات التي تحافظ على بيانات المستخدم
تحتاج التوقيع بالمفتاح نفسه؛ لا تلغِ تثبيت إصدار يحتوي بيانات لتجاوز تعارض التوقيع.
تحتاج نسخة الإنتاج إلى مفتاح توقيع محفوظ بشكل آمن قبل الاعتماد عليها.

## Windows

المصدر في `windows/`. يخزن SQLite تحت:

```text
%APPDATA%\AlsafaAccounting\databases
```

ملف التثبيت الناتج غير موقّع بشهادة توزيع Windows؛ قد يعرض Windows تحذيرًا
عن الناشر. لا يحذف برنامج الإزالة بيانات التطبيق تلقائيًا.

## البناء

يشغّل `Build offline accounting installers` في GitHub Actions بناء APK التجريبي
ومثبّت Windows، ويضعهما ضمن ملفات نتيجة التشغيل. يمكن أيضًا تشغيله يدويًا.
تستعمل هذه العملية بناء Android الأصلي، ولا تستعمل Expo prebuild أو EAS.
معاينة Expo تبقى معاينة للواجهة، وليست APK.

من جذر مساحة العمل:

```sh
node scripts/build-offline-accounting.mjs
node native/tests/sqlite-browser.cjs
```

اختبار التخزين يستعمل SQLite الأصلية في Node، ويختبر إغلاق القاعدة وإعادة فتحها
وإلغاء الكتابة. لا يُغني ذلك عن اختبار ملفي التثبيت على Android وWindows فعليين.
